# mollendorff-ai.github.io

Home page of Möllendorff AI: open-source tools for finance and AI agents, starting with [Forge](https://github.com/mollendorff-ai/forge). Served at <https://mollendorff.ai/>.

Two static pages, `index.html` in English and `fr/index.html` in Quebec French, each with its styles inline; the top bar links one to the other. It runs no scripts, sets no cookies and loads nothing from other sites. The model shown at the top is a real one: saved as `shop.yaml`, `forge calculate shop.yaml` gives the numbers beside it.

`img/card.png` is the picture shown when the link is shared; `img/studio-phone.jpg` comes from Forge's `docs/images/studio-phone.png`.
